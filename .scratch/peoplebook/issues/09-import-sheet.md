# 09: 导入预览 sheet 与文件导入

## Parent

- #1（Spec: 人脉簿 v1）

## What to build

把导入域链路接上界面：工具栏「导入 CSV」打开 sheet，选择 UTF-8 CSV 文件或点「示例 CSV」一键体验；**导入预览**逐行展示姓名/电话/公司与标记（跳过默认勾、疑似重复橙色徽标），每行可改判是否导入；底部实时统计「共 X 行 · 将导入 Y · 跳过 Z」；确认后按默认普通层级入库，取消不落库；解析错误给出明确中文提示。

## Acceptance criteria

- [ ] 文件选择器限定 CSV/文本类型；读取失败有提示
- [ ] 预览行内 Toggle 与标记规则一致（跳过/疑似重复默认值来自域规则，可人工改判）
- [ ] 计数实时反映勾选变化；无可导入行时导入按钮禁用
- [ ] 确认导入后联系人出现在列表（层级默认普通）；取消/关闭 sheet 不产生任何数据
- [ ] 缺「姓名」列等导入错误有中文提示
