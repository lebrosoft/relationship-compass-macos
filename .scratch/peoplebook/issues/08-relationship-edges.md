# 08: 联系人间关系连线

## Parent

- #1（Spec: 人脉簿 v1）

## What to build

右栏的**联系人间关系**区：为当前联系人从其余联系人中选一端、选固定七类之一建立关系边；展示为「另一端姓名 — 类型」并可删除。这是"梳理人脉"区别于普通通讯录的核心场景。

## Acceptance criteria

- [ ] 可以建立关系边（两端都出现在各自的关系区，经介绍认识等七类可选）
- [ ] 不能把自己连给自己；重复边由用户自行处理（v1 不做合并）
- [ ] 删除边立即生效
- [ ] 关系边落库，重启后仍在

## Blocked by

- #7（06 三栏界面骨架与联系人资料编辑）
