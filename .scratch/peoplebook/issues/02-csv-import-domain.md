# 02: CSV 导入域链路（含 CRLF 解析修复）

## Parent

- #1（Spec: 人脉簿 v1）

## What to build

UTF-8 CSV → 导入预览候选域链路：解码剥 BOM、RFC4180 风格解析（引号内的逗号/换行/转义引号）、表头校验、去重标记（姓名+电话同时命中 → 跳过；仅姓名命中 → 疑似重复，默认仍导入）。**必须修复**：当前解析器按字素簇切分，`\r\n` 在 Swift 中是单个字素簇导致 CRLF 文件被解析成一行——改按 Unicode scalar 逐个处理。临时 scratch 测试文件一并移除。

## Acceptance criteria

- [ ] CRLF 与 LF 行尾的 CSV 解析结果一致（三行数据 → 三行）
- [ ] 引号内的逗号、换行、转义引号解析正确
- [ ] 缺「姓名」列 / 无表头 / 无数据行 三类输入返回各自的错误值，可被 UI 区分
- [ ] 电话归一化：去非数字、剥 +86 前缀；"138 0000 0001" 与 "138-0000-0001" 视为同一号码
- [ ] 去重标记规则测试通过；仓库中不再有 scratch 测试

## Blocked by

None (can start immediately)
