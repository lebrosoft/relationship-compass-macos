# 06: 三栏界面骨架与联系人资料编辑

## Parent

- #1（Spec: 人脉簿 v1）

## What to build

可运行的 SwiftUI 三栏窗口：左栏搜索+联系人列表（姓名、公司/职位副标、层级徽标、逾期红点），中栏时间线区容器，右栏资料区（姓名/电话/邮箱/公司/职位/层级/备注的编辑与保存）。搜索框直接消费搜索域函数（含互动笔记次级命中的聚合展示）。

## Acceptance criteria

- [ ] `swift run` 出现三栏窗口，选中联系人驱动中、右两栏
- [ ] 列表行显示姓名 + 公司/职位 + 层级色；**逾期**者挂红点（悬停说明阈值）
- [ ] 搜索框与搜索域函数接线：属性主命中与互动笔记次级命中都能出结果
- [ ] 资料可编辑并保存（脏状态提示 + 快捷键保存）；层级三选一即时改写阈值表现
- [ ] 删除联系人后，其互动与关系边在界面与库中一并消失
