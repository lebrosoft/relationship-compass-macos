# 04: 搜索（主命中 + 互动笔记次级聚合）

## Parent

- #1（Spec: 人脉簿 v1）

## What to build

搜索域规则：查询命中姓名、公司、职位、备注（主命中），互动笔记作为次级结果聚合到对应联系人下。这是左栏搜索框直接消费的域函数。

## Acceptance criteria

- [ ] 主命中覆盖姓名 / 公司 / 职位 / 备注，大小写与变音不敏感
- [ ] 仅互动笔记命中时，结果是该联系人的次级结果，笔记列表按日期倒序聚合
- [ ] 空查询返回全部联系人且保持传入顺序；主命中结果排于仅次级命中的联系人之前
- [ ] 未命中返回空

## Blocked by

None (can start immediately)
