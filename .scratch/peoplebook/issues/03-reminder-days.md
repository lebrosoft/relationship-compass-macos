# 03: 提醒阈值与自然日日期计算

## Parent

- #1（Spec: 人脉簿 v1）

## What to build

"该维护谁"的判定域函数（ADR 0002）：按层级阈值判定逾期，并提供自然日天数计算与最近互动取值。永远不做逐联系人自定义阈值、不做自动热度衰减（ADR 0002 的明确否决）。

## Acceptance criteria

- [ ] 重点 >30 天、普通 >90 天逾期；恰好 30/90 天不逾期；冷淡从不逾期
- [ ] 从未有过互动记录的联系人永不逾期（即使层级是重点）
- [ ] 天数按自然日计（起点零点）：23:50 → 次日 00:10 记 1 天；同一天记 0 天
- [ ] 测试用固定时钟（固定日历与时区），不依赖真实当前时间

## Blocked by

None (can start immediately)
