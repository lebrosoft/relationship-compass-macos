# 07: 互动时间线的增删与逾期横幅

## Parent

- #1（Spec: 人脉簿 v1）

## What to build

中栏从容器变成品：按日期倒序的**互动**时间线（类型 · 日期 · 笔记），底部常驻新增表单（固定六类互动类型、日期、可空笔记），每条可删除；逾期时顶部红色横幅显示「距上次互动 N 天（阈值 X 天）」。

## Acceptance criteria

- [ ] 新增互动立即出现在时间线顶部，数据落库，重启后仍在
- [ ] 六类互动类型固定可选（喝咖啡/面谈、电话、微信、邮件、会议、其他）
- [ ] 删除记错的互动立即生效
- [ ] 逾期横幅天数与阈值来自提醒域函数，不在 UI 复制阈值逻辑
